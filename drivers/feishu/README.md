# 飞书云文档驱动

## 支持范围

- 应用模式挂载一个明确授权的飞书云空间文件夹，支持文件夹链接或 Token；用户模式还支持留空根目录，挂载授权用户的“我的空间”。
- 应用身份（tenant）与用户身份（user），自动缓存、提前刷新令牌。
- 分页浏览目录、下载普通文件、新建文件夹、上传普通文件；大文件使用分片上传。
- 飞书文档（doc/docx）导出为 DOCX 或 PDF，电子表格（sheet）导出为 XLSX。
- 下载经过 OpenList 服务端，访问令牌不下发给文件访问者。
- 默认只读；上传和新建文件夹需要关闭只读并授予相应飞书权限。

本版不实现 Wiki、快捷方式解析、多维表格导出、移动、复制、重命名、覆盖上传，以及将普通文件导入为原生文档。目录中未适配类型仍可见，下载返回不支持。空文件上传受飞书 API 限制，返回明确错误。

## 飞书应用配置

创建企业自建应用，配置并发布所需的云空间权限。本驱动的用户授权请求使用 `drive:drive offline_access`，需在应用后台开通并发布这些权限；`offline_access` 用于获得可自动续期的用户凭据。应用模式只使用租户令牌接口，不需要用户授权。

接口权限和文件权限是两件事：应用模式需要目标目录对应用具有相应权限；用户模式需要授权用户具有目标目录及文件的访问权限。开启下载、导出或写操作，还需要资源允许对应操作。

## 应用模式

1. 添加 `Feishu` 存储，认证模式选 `tenant`。
2. 填写 App ID、App Secret、根文件夹 Token 或完整链接。
3. 保持只读，先保存并验证目录浏览和下载；需要上传时再关闭只读。

租户令牌仅在内存缓存，重启后自动获取。应用身份并不等于可以读取用户的整个云空间。

## 用户模式

1. 在飞书应用后台登记 OAuth 回调地址：`https://你的域名/api/public/feishu/callback`。OpenList 使用子路径时，在 `/api` 前加入子路径。
2. 添加 `Feishu` 存储，认证模式选 `user`，填写应用凭据和同一回调地址；根文件夹可留空，默认挂载授权用户的“我的空间”，也可填写具体文件夹来限制挂载范围。
3. 保存。首次未授权显示“等待飞书用户授权”，不会因尚未授权而提示保存失败。
4. 在存储列表点击“飞书授权 / 重新授权”，允许弹窗，完成飞书授权。
5. 授权成功后关闭窗口，刷新存储列表。回调会验证根目录权限；若失败，按存储状态检查权限后重新加载。

管理页面、授权接口和回调应通过同一公开来源访问；反向代理须保留外部 Host。生产环境使用 HTTPS，HTTP 仅允许 loopback 开发地址。回调支持 OpenList 的部署子路径。授权事务存活十分钟，仅可消费一次，并通过 HttpOnly、SameSite=Lax Cookie 绑定发起授权的浏览器；进程重启或存储配置重新加载后，需要重新发起尚未完成的授权。

访问令牌、轮换后的刷新令牌和到期时间保存在该存储的 addition 中。使用 OpenList 现有数据库和备份保护机制。不要将同一个会轮换的用户刷新令牌复制到多个存储或进程；需要多个挂载时分别授权。刷新令牌被撤销或过期后，使用“重新授权”。令牌交换不自动重试；响应丢失可能需要重新授权。

两种模式的 App ID、App Secret 都是必填项：用户模式同样通过应用发起 OAuth 和刷新用户令牌。应用模式不显示 OAuth 回调项，用户模式要求填写；根目录仅在应用模式必填。自动维护的令牌字段不在编辑表单中展示。修改认证模式或应用凭据会清空当前编辑配置中的旧用户令牌，需要重新授权。

## 行为约定与限制

- 支持删除飞书云空间中的文件和文件夹。删除文件夹时等待飞书异步任务成功，操作需要对应的飞书删除权限。只读挂载和挂载根目录禁止删除。
- 普通文件原样上传，不转换为飞书原生文档；拒绝同名上传，不先删除旧文件。同一驱动实例串行执行写操作，但无法阻止飞书客户端或其他实例同时新建同名文件。
- 原生文档在列表中附加导出扩展名，例如 `周报.docx`；同名对象附加完整 Token，保证各对象可寻址。名称中的路径分隔符转换为全角字符。
- 云空间列表 API 不返回文件字节数，列表中的文件大小标为未知（`-1`）。实际下载前探测普通文件大小，或使用导出结果中的大小，通过 `Link.ContentLength` 提供准确下载长度。依赖 PROPFIND 中准确文件大小的 WebDAV 客户端，需要在目标客户端上验证；本版不为目录浏览预先导出所有文档。
- 下载提供 Range 读取；上游忽略 Range 时通过顺序读取跳过偏移，可能增加流量和等待时间。上游返回错误范围会失败，不返回错误的文件字节。
- API 重定向不自动跟随，避免凭据被发往其他来源。若租户实际返回重定向，需要先核对官方响应契约再适配。
- 导出任务按对象、修改时间和格式合并并发请求，成功结果短期缓存一分钟；失败结果可重试，单次下载解析最多等待两分钟。
- API 使用保守的实例内限流；GET 请求对 HTTP 429/5xx 有限重试。租户级配额仍以飞书实际限制为准。
- OpenList 的两种访问日志均跳过 OAuth 回调。外部反向代理也应避免记录该回调的查询参数，防止授权码进入日志。

## 验证

`go test ./drivers/feishu ./server/handles ./server/middlewares` 覆盖令牌刷新、数据库持久化与过期写入防护、目录分页、名称冲突、上传分片校验、Range、导出任务合并、OAuth 浏览器绑定及状态重放。

上线前使用目标租户分别验证应用和用户身份、实际资源权限、普通文件及文档下载、大文件上传、视频拖动，以及计划使用的 WebDAV 客户端。自动化测试不替代真实飞书凭据联调。
